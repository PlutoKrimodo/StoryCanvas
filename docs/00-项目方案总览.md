## 4. 数据库表结构

### 4.1 核心表

| 表名 | 说明 | 主要字段 |
|------|------|---------|
| users | 用户表 | id, username, email, password_hash |
| books | 绘本表 | id, user_id, title, description |
| book_pages | 页面表 | id, book_id, page_number, canvas_data |
| page_elements | 元素表 | id, page_id, element_type, position_x/y |
| characters | 角色表 | id, user_id, name, appearance |
| generation_tasks | 生成任务表 | id, user_id, prompt, status |
| generated_images | 生成图片表 | id, task_id, file_path |

### 4.2 关系图

```
users ──1:N──▶ books ──1:N──▶ book_pages ──1:N──▶ page_elements
  │
  ├──1:N──▶ characters
  │
  └──1:N──▶ generation_tasks ──1:N──▶ generated_images
```

## 5. API 设计总结

### 5.1 模块划分

| 模块 | 前缀 | 主要接口 |
|------|------|---------|
| 认证 | /api/v1/auth | register, login, logout, refresh |
| 用户 | /api/v1/users | me, update, change-password |
| 绘本 | /api/v1/books | create, list, get, update, delete |
| 页面 | /api/v1/pages | create, get, update, delete |
| 元素 | /api/v1/elements | add, update, delete |
| 角色 | /api/v1/characters | create, list, get, update, delete |
| 生成 | /api/v1/generation | create, status, history |
| 图片 | /api/v1/images | upload, get, delete |
| 导出 | /api/v1/books/{id}/export | export |

## 9. 注意事项

### 9.1 开发建议

1. **先完成后端 API，再完成前端界面**
2. **使用 Mock Provider 进行测试，不依赖真实 AI API**
3. **定期提交代码，保持小步迭代**
4. **边开发边记录，为课程报告积累素材**

### 9.2 常见问题

1. **Drogon 学习曲线较陡**
   - 参考官方示例
   - 查看 Drogon 文档

2. **Fabric.js 复杂度**
   - 从简单功能开始
   - 参考 Fabric.js 文档

3. **AI API 不稳定**
   - 使用 Mock Provider
   - 准备备份方案

### 9.3 资源链接

- Drogon 文档: https://drogonframework.com/
- FastAPI 文档: https://fastapi.tiangolo.com/
- React 文档: https://react.dev/
