## 4. 数据库表结构

### 4.1 核心表

| 表名 | 说明 | 主要字段 |
|------|------|---------|
| users | 用户表 | id, username, email, password_hash（bcrypt 哈希，加密存储）, is_active |
| books | 绘本表 | id, user_id, title, description |
| book_pages | 页容器表 | id, book_id, page_number, title, thumbnail |
| page_elements | 元素表 | **本轮放弃使用**（在线编辑遗留） |
| characters | 角色表 | id, user_id, name, appearance（第二阶段） |
| generation_tasks | 生成任务表 | id, user_id, prompt, status |
| generated_images | 生成图片表 | id, task_id, file_path |

### 4.2 关系图

```
users ──1:N──▶ books ──1:N──▶ book_pages
  │
  ├──1:N──▶ characters
  │
  └──1:N──▶ generation_tasks ──1:N──▶ generated_images
```

## 9. 注意事项

### 9.1 开发建议

1. **先完成后端 API，再完成前端界面**
2. **使用 Mock Provider 进行测试，不依赖真实 AI API**
3. **定期提交代码，保持小步迭代**
4. **边开发边记录，为课程报告积累素材**

### 9.2 常见问题

1. **Drogon 学习曲线较陡**
   - 参考官方示例
   - 查看 Drogon 文档

2. **加密库集成**
   - 骨架阶段先验证 bcrypt / OpenSSL 的编译与链接
   - 密钥一律走环境变量，避免硬编码

3. **AI API 不稳定**
   - 使用 Mock Provider
   - 准备备份方案

### 9.3 资源链接

- Drogon 文档: https://drogonframework.com/
- FastAPI 文档: https://fastapi.tiangolo.com/
- React 文档: https://react.dev/
- PostgreSQL 文档: https://www.postgresql.org/docs/
