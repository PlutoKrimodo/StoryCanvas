# 数据库设计

## 基于生成式 AI 的儿童绘本智能创作与图像生成系统

**版本**: 2.0  
**日期**: 2026-09-19  
**作者**: StoryCanvas 开发团队

> **v2.0 修订**：范围收敛为**用户管理**与**智能图像生成**两大子系统，**在线编辑子系统整体放弃**。
> `page_elements` 表与 `book_pages.canvas_data` 字段不再写入；`users.password_hash` 明确为 **bcrypt 加盐哈希（加密存储）**。权威方案见 `docs/16-项目实施方案.md`。

## 2. 核心实体设计

### 2.1 users 表（用户表）

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    avatar VARCHAR(500),
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_username ON users(username);
```

**字段说明**:
- `id`: 用户唯一标识，UUID 类型
- `username`: 用户名，唯一
- `email`: 邮箱，唯一
- `password_hash`: 密码哈希值（**bcrypt 加盐哈希，cost ≥ 12**）；仅存哈希，禁止明文或可逆加密存储
- `avatar`: 头像文件路径
- `is_active`: 账号是否激活
- `created_at`: 创建时间
- `updated_at`: 更新时间

### 2.2 books 表（绘本表）

```sql
CREATE TABLE books (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    cover_image VARCHAR(500),
    status VARCHAR(20) DEFAULT 'draft' CHECK (status IN ('draft', 'published', 'archived')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_books_user_id ON books(user_id);
CREATE INDEX idx_books_status ON books(status);
```

**字段说明**:
- `id`: 绘本唯一标识
- `user_id`: 所属用户
- `title`: 绘本标题
- `description`: 绘本描述
- `cover_image`: 封面图片路径
- `status`: 绘本状态
- `created_at`: 创建时间
- `updated_at`: 更新时间

### 2.3 book_pages 表（绘本页面表）

```sql
CREATE TABLE book_pages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    book_id UUID NOT NULL REFERENCES books(id) ON DELETE CASCADE,
    page_number INTEGER NOT NULL,
    title VARCHAR(200),
    canvas_data JSONB DEFAULT '{}',
    thumbnail VARCHAR(500),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(book_id, page_number)
);

-- 索引
CREATE INDEX idx_book_pages_book_id ON book_pages(book_id);
```

**字段说明**:
- `id`: 页面唯一标识
- `book_id`: 所属绘本
- `page_number`: 页码
- `title`: 页面标题
- `canvas_data`: **本轮不使用**（原用于存储 Fabric.js 画布状态；随在线编辑子系统放弃，不再写入）
- `thumbnail`: 页面缩略图路径
- `created_at`: 创建时间
- `updated_at`: 更新时间

### 2.4 page_elements 表（页面元素表）——**本轮放弃使用**

> 该表属在线编辑子系统遗留，本轮不写入；后续可直接移除。以下内容仅作历史留档。

```sql
CREATE TABLE page_elements (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    page_id UUID NOT NULL REFERENCES book_pages(id) ON DELETE CASCADE,
    element_type VARCHAR(50) NOT NULL CHECK (element_type IN ('image', 'text', 'shape')),
    position_x FLOAT DEFAULT 0,
    position_y FLOAT DEFAULT 0,
    width FLOAT,
    height FLOAT,
    rotation FLOAT DEFAULT 0,
    style_data JSONB DEFAULT '{}',
    content TEXT,
    z_index INTEGER DEFAULT 0,
    is_visible BOOLEAN DEFAULT true,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_page_elements_page_id ON page_elements(page_id);
CREATE INDEX idx_page_elements_z_index ON page_elements(page_id, z_index);
```

**字段说明**:
- `id`: 元素唯一标识
- `page_id`: 所属页面
- `element_type`: 元素类型（图片/文字/形状）
- `position_x`: X 坐标
- `position_y`: Y 坐标
- `width`: 宽度
- `height`: 高度
- `rotation`: 旋转角度
- `style_data`: 样式数据（JSON 格式）
- `content`: 文字内容
- `z_index`: 图层顺序
- `is_visible`: 是否可见
- `created_at`: 创建时间
- `updated_at`: 更新时间

### 2.5 characters 表（角色表）

```sql
CREATE TABLE characters (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    age INTEGER,
    appearance TEXT,
    style_info JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_characters_user_id ON characters(user_id);
```

**字段说明**:
- `id`: 角色唯一标识
- `user_id`: 所属用户
- `name`: 角色名称
- `description`: 角色描述
- `age`: 角色年龄
- `appearance`: 外观描述
- `style_info`: 风格信息（JSON 格式）
- `created_at`: 创建时间
- `updated_at`: 更新时间

### 2.6 generation_tasks 表（生成任务表）

```sql
CREATE TABLE generation_tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    book_id UUID REFERENCES books(id) ON DELETE SET NULL,
    page_id UUID REFERENCES book_pages(id) ON DELETE SET NULL,
    prompt TEXT NOT NULL,
    original_text TEXT,
    parsed_data JSONB,
    status VARCHAR(20) DEFAULT 'pending' CHECK (status IN ('pending', 'processing', 'completed', 'failed')),
    result_url VARCHAR(500),
    error_message TEXT,
    model_used VARCHAR(100),
    parameters JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    completed_at TIMESTAMP WITH TIME ZONE
);

-- 索引
CREATE INDEX idx_generation_tasks_user_id ON generation_tasks(user_id);
CREATE INDEX idx_generation_tasks_book_id ON generation_tasks(book_id);
CREATE INDEX idx_generation_tasks_status ON generation_tasks(status);
```

**字段说明**:
- `id`: 任务唯一标识
- `user_id`: 所属用户
- `book_id`: 关联绘本（可选）
- `page_id`: 关联页面（可选）
- `prompt`: 生成提示词
- `original_text`: 原始输入文本
- `parsed_data`: 解析后的结构化数据（JSON）
- `status`: 任务状态
- `result_url`: 生成结果图片路径
- `error_message`: 错误信息
- `model_used`: 使用的模型
- `parameters`: 生成参数（JSON）
- `created_at`: 创建时间
- `updated_at`: 更新时间
- `completed_at`: 完成时间

### 2.7 generated_images 表（生成图片表）

```sql
CREATE TABLE generated_images (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    task_id UUID NOT NULL REFERENCES generation_tasks(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    original_url VARCHAR(500),
    file_path VARCHAR(500) NOT NULL,
    file_size INTEGER,
    width INTEGER,
    height INTEGER,
    format VARCHAR(20),
    prompt_used TEXT,
    parameters JSONB DEFAULT '{}',
    is_favorite BOOLEAN DEFAULT false,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_generated_images_task_id ON generated_images(task_id);
CREATE INDEX idx_generated_images_user_id ON generated_images(user_id);
```

**字段说明**:
- `id`: 图片唯一标识
- `task_id`: 关联生成任务
- `user_id`: 所属用户
- `original_url`: 原始 API 返回的 URL
- `file_path`: 本地存储路径
- `file_size`: 文件大小（字节）
- `width`: 图片宽度
- `height`: 图片高度
- `format`: 图片格式
- `prompt_used`: 使用的提示词
- `parameters`: 生成参数（JSON）
- `is_favorite`: 是否收藏
- `created_at`: 创建时间

## 3. 删除策略

### 3.1 级联删除

- 删除用户时，级联删除其所有绘本、角色、生成任务
- 删除绘本时，级联删除其所有页面和生成任务
- 删除页面时，级联删除其所有元素
- 删除生成任务时，级联删除其生成的图片

### 3.2 软删除（可选）

对于重要数据，可考虑软删除：

```sql
ALTER TABLE users ADD COLUMN deleted_at TIMESTAMP WITH TIME ZONE;
ALTER TABLE books ADD COLUMN deleted_at TIMESTAMP WITH TIME ZONE;
```

### 3.3 文件清理

- 删除数据库记录时，同时清理对应文件
- 定期清理临时文件和未使用的文件

## 4. 状态字段设计

### 4.1 绘本状态

| 状态 | 说明 |
|------|------|
| draft | 草稿，正在编辑中 |
| published | 已发布，完成创作 |
| archived | 已归档，不再使用 |

### 4.2 生成任务状态

| 状态 | 说明 |
|------|------|
| pending | 待处理，等待执行 |
| processing | 处理中，正在生成 |
| completed | 已完成，生成成功 |
| failed | 失败，生成失败 |

## 5. 时间字段设计

### 5.1 统一时间字段

所有表都包含以下时间字段：

- `created_at`: 创建时间，自动设置
- `updated_at`: 更新时间，自动更新

### 5.2 时间格式

- 使用 `TIMESTAMP WITH TIME ZONE`
- 存储 UTC 时间
- 前端显示时转换为本地时间

## 10. 设计说明

### 10.1 为什么使用 UUID

- 全局唯一，避免分布式环境下的冲突
- 不暴露数据量信息
- 可在客户端生成，减少数据库压力

### 10.2 为什么使用 JSONB

- 灵活存储结构化数据
- 支持索引和查询
- 适合存储配置和元数据

### 10.3 为什么分离 page_elements ——**本轮放弃使用**

- 原设计意图：便于单独操作元素、支持元素级权限控制、便于增删改查
- 本轮状态：随在线编辑子系统一并放弃，表结构保留但**不再写入**

### 10.4 为什么保留 generated_images

- 记录生成历史
- 支持图片复用
- 便于统计分析
