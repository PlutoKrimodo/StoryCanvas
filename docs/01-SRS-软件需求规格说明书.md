# 软件需求规格说明书（SRS）

## 基于生成式 AI 的儿童绘本智能创作与图像生成系统

**版本**: 2.0  
**日期**: 2026-09-19  
**作者**: StoryCanvas 开发团队

> **v2.0 修订**：范围收敛为**用户管理**与**智能图像生成**两大子系统，**在线编辑子系统整体放弃**；并强化密码与敏感数据加密存储要求（第 4.4、10 节）。权威方案见 `docs/16-项目实施方案.md`。

## 1. 项目背景

### 1.1 项目背景

随着人工智能技术的快速发展，生成式 AI 已经在图像创作领域展现出强大的能力。儿童绘本作为一种重要的儿童教育和娱乐形式，其创作过程通常需要专业的插画师和较长的创作周期。

本项目旨在利用生成式 AI 技术，构建一个面向普通用户的儿童绘本智能创作与图像生成系统，使用户能够通过自然语言描述生成绘本插画，大幅降低绘本创作的门槛和成本。

### 1.2 项目目标

- 构建一个儿童绘本智能创作与图像生成平台
- **实现 AI 驱动的图像生成能力（本轮重点）**
- 提供安全的用户账号体系与密码加密存储
- 支持绘本项目的创建与生成结果管理
- 具备良好的用户体验和系统稳定性

> 说明：原「在线编辑器」「多页绘本」目标因时间原因在本轮放弃，详见第 3.3 节与第 11.4 节。

### 1.3 项目范围

本项目包括两个核心子系统：

1. **用户管理子系统**：注册、登录、登出、JWT 认证与 Token 刷新、用户信息与密码管理、绘本项目管理、密码加密存储。
2. **智能图像生成子系统（本轮重点）**：文本解析、Prompt 优化、图像生成、任务状态管理、结果预览、重新生成。

**明确不在本项目范围内**：在线编辑子系统（Canvas 画布、图片/文字元素编辑、移动/缩放/旋转、撤销/重做、图文排版、PDF 导出）。

## 2. 用户角色

### 2.1 系统用户

- **普通用户**: 使用系统创建和编辑儿童绘本
- **管理员**: 管理系统用户和内容（可选功能）

### 2.2 用户特征

- 年龄：18岁以上，有基本的计算机操作能力
- 技术水平：无需专业设计经验
- 使用场景：家庭、教育机构、个人创作

## 3. 功能需求

### 3.1 用户管理子系统

#### 3.1.1 用户注册
- **功能描述**: 用户可以通过邮箱或用户名注册账号
- **输入**: 用户名、密码、邮箱
- **输出**: 注册成功/失败提示
- **优先级**: MVP 必须实现

#### 3.1.2 用户登录
- **功能描述**: 用户使用账号密码登录系统
- **输入**: 用户名/邮箱、密码
- **输出**: JWT Token、用户信息
- **优先级**: MVP 必须实现

#### 3.1.3 用户退出
- **功能描述**: 用户退出登录状态
- **输出**: 登出成功提示
- **优先级**: MVP 必须实现

#### 3.1.4 JWT 身份认证
- **功能描述**: 基于 JWT 的身份验证机制
- **输出**: Access Token + Refresh Token
- **优先级**: MVP 必须实现

#### 3.1.5 用户信息管理
- **功能描述**: 用户可以查看和修改个人信息
- **输入**: 用户名、邮箱、头像
- **输出**: 更新后的用户信息
- **优先级**: MVP 必须实现

#### 3.1.6 密码修改
- **功能描述**: 用户可以修改登录密码
- **输入**: 原密码、新密码
- **输出**: 修改成功/失败提示
- **优先级**: MVP 必须实现

#### 3.1.7 用户绘本项目管理
- **功能描述**: 用户可以查看、删除自己创建的绘本
- **输出**: 绘本列表、操作结果
- **优先级**: MVP 必须实现

### 3.2 智能图像生成子系统

#### 3.2.1 文本解析
- **功能描述**: 解析用户输入的自然语言描述
- **输入**: 用户故事文本
- **输出**: 结构化绘本描述
- **优先级**: MVP 必须实现

#### 3.2.2 Prompt 解析与优化
- **功能描述**: 将结构化描述转换为图像生成提示词
- **输入**: 结构化绘本描述
- **输出**: 优化后的 Prompt
- **优先级**: MVP 必须实现

#### 3.2.3 儿童绘本场景理解
- **功能描述**: 针对儿童绘本的特点进行场景理解
- **输出**: 适合儿童的风格和内容
- **优先级**: 第二阶段实现

#### 3.2.4 图像生成
- **功能描述**: 调用 AI API 生成图像
- **输入**: 优化后的 Prompt
- **输出**: 生成的图像
- **优先级**: MVP 必须实现

#### 3.2.5 生成结果预览
- **功能描述**: 展示生成的图像供用户预览
- **输出**: 图像预览界面
- **优先级**: MVP 必须实现

#### 3.2.6 重新生成
- **功能描述**: 用户可以重新生成图像
- **输出**: 新的生成图像
- **优先级**: MVP 必须实现

#### 3.2.7 生成任务状态管理
- **功能描述**: 跟踪和管理图像生成任务的状态
- **输出**: 任务状态信息
- **优先级**: MVP 必须实现

#### 3.2.8 生成历史
- **功能描述**: 记录和展示用户的生成历史
- **输出**: 历史记录列表
- **优先级**: 第二阶段实现

#### 3.2.9 角色管理/角色一致性
- **功能描述**: 管理角色信息，确保多页绘本中人物一致性
- **输出**: 角色列表、一致性图像
- **优先级**: 第二阶段实现

### 3.3 在线编辑子系统（本轮放弃）

> **状态：整体放弃（时间原因）。**
>
> 原属本子系统的以下能力不再纳入本轮实现：Canvas 画布、图片上传/移动/缩放/旋转/裁剪、文字添加与排版、撤销/重做、页面管理、PDF 导出。
>
> 与之配套的 `page_elements` 表、`book_pages.canvas_data` 画布字段与前端 Fabric.js 依赖同步移除或不再使用。绘本「页」容器能力保留，仅用于承载生成的图片，不提供画布编辑。

## 4. 非功能需求

### 4.1 性能要求
- 页面加载时间：< 3 秒
- API 响应时间：< 500ms（非 AI 任务）
- AI 生成任务：异步处理，不阻塞用户操作
- 支持并发用户数：100+

### 4.2 可用性要求
- 界面简洁直观
- 操作流程清晰
- 提供必要的操作提示和反馈

### 4.3 可靠性要求
- 系统稳定运行
- 数据定期备份
- 错误处理完善

### 4.4 安全性要求
- 用户密码使用 **bcrypt 加盐哈希**存储（单向不可逆，禁止明文/可逆加密）
- 敏感配置（JWT 密钥、数据库口令、第三方 API Key）经环境变量/密钥仓库注入，禁止硬编码与入库
- 确需落库的敏感字段使用 **AES-256-GCM** 加密存储
- JWT 认证机制（双 Token，支持刷新与撤销）
- API 权限控制与资源归属校验
- 传输加密：生产环境全程 HTTPS/TLS 1.2+
- 日志脱敏：密码、Token、密钥不落日志

### 4.5 可维护性要求
- 代码结构清晰
- 模块化设计
- 完善的日志记录

## 6. 用例分析

### 6.1 用例图

```
用户
  |
  ├── 注册账号
  ├── 登录系统
  ├── 管理个人信息与密码
  ├── 创建绘本项目
  ├── 输入故事文本
  ├── 生成 AI 图像
  ├── 预览生成结果
  ├── 重新生成
  ├── 保存到绘本
  └── 管理个人绘本
```

### 6.2 核心用例描述

#### 用例 1: 用户注册
- **参与者**: 访客
- **前置条件**: 无
- **基本流程**:
  1. 访客点击注册按钮
  2. 系统显示注册表单
  3. 访客填写用户名、邮箱、密码
  4. 系统验证输入
  5. 系统创建用户账号
  6. 系统返回注册成功
- **后置条件**: 用户账号创建成功

#### 用例 2: 创建绘本
- **参与者**: 已登录用户
- **前置条件**: 用户已登录
- **基本流程**:
  1. 用户点击创建绘本按钮
  2. 系统显示创建表单
  3. 用户填写绘本标题、描述
  4. 系统创建绘本项目
  5. 系统返回创建成功
- **后置条件**: 绘本项目创建成功

## 8. 异常情况

### 8.1 网络异常
- AI API 调用超时
- 网络连接中断
- 服务器无响应

### 8.2 数据异常
- 用户输入非法字符
- 文件格式不支持
- 文件大小超限

### 8.3 业务异常
- 用户名已存在
- 密码错误

## 9. 权限需求

### 9.1 访问控制
- 未登录用户：只能访问注册/登录页面
- 已登录用户：可以访问所有个人功能
- 用户只能操作自己的绘本

### 9.2 API 权限
- 公开 API：注册、登录
- 认证 API：需要 JWT Token
- 资源 API：需要资源所有权验证

## 10. 数据安全要求

> 详细的加密存储设计见 `docs/16-项目实施方案.md` 第 6.6 节。

### 10.1 密码安全
- 使用 **bcrypt 加盐哈希**存储（cost ≥ 12），单向不可逆
- 禁止明文、MD5/SHA1 直存、可逆加密存储密码
- 密码强度要求：最少 8 位，包含字母和数字
- 修改密码后撤销该用户已签发的 Token
- 登录失败不区分「用户不存在/密码错误」，避免账号枚举

### 10.2 数据传输
- 生产环境使用 HTTPS/TLS 1.2+ 加密传输
- JWT Token 安全存储（Access Token 短寿命，Refresh Token 优先 HttpOnly Cookie）

### 10.3 数据存储
- **凭据类信息（密钥、口令、外部 API Key）不落库**，经环境变量/密钥仓库注入
- **确需落库的敏感字段使用 AES-256-GCM 加密存储**，密钥独立注入
- 如实现服务端 Token 撤销，仅存 Refresh Token 的 SHA-256 哈希
- 上传/生成文件清理隐私元数据（EXIF）
- 定期数据备份

## 11. 功能优先级分类

### 11.1 MVP 必须实现（Phase 1）
- 用户注册/登录/登出、JWT 认证与 Token 刷新
- 用户信息与密码管理（bcrypt 加密存储）
- 绘本项目管理
- AI 文本解析与 Prompt 优化
- AI 图像生成、任务状态查询
- 生成结果预览、重新生成

### 11.2 第二阶段实现（Phase 2）
- 生成历史
- 角色一致性与角色管理
- 多艺术风格与参数调优
- 性能优化

### 11.3 可选增强功能
- 单张图片下载、图片打包导出
- 协作功能
- 模板系统
- 高级 AI 功能

- 在线编辑子系统全部功能（画布、元素编辑、文字排版、撤销/重做）
- 多页排版编辑
- PDF 合成导出
