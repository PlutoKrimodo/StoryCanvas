# 软件需求规格说明书（SRS）

## 基于生成式 AI 的儿童绘本智能创作与在线编辑系统

**版本**: 1.0  
**日期**: 2026-09-17  
**作者**: StoryCanvas 开发团队

---

## 1. 项目背景

### 1.1 项目背景

随着人工智能技术的快速发展，生成式 AI 已经在图像创作领域展现出强大的能力。儿童绘本作为一种重要的儿童教育和娱乐形式，其创作过程通常需要专业的插画师和较长的创作周期。

本项目旨在利用生成式 AI 技术，构建一个面向普通用户的儿童绘本智能创作系统，使用户能够通过自然语言描述生成绘本插画，并提供在线编辑功能，大幅降低绘本创作的门槛和成本。

### 1.2 项目目标

- 构建一个功能完整的儿童绘本创作平台
- 实现 AI 驱动的图像生成能力
- 提供直观易用的在线编辑器
- 支持多页绘本的创建和管理
- 具备良好的用户体验和系统稳定性

### 1.3 项目范围

本项目包括三个核心子系统：
1. 用户管理子系统
2. 智能图像生成子系统
3. 在线编辑子系统

---

## 2. 用户角色

### 2.1 系统用户

- **普通用户**: 使用系统创建和编辑儿童绘本
- **管理员**: 管理系统用户和内容（可选功能）

### 2.2 用户特征

- 年龄：18岁以上，有基本的计算机操作能力
- 技术水平：无需专业设计经验
- 使用场景：家庭、教育机构、个人创作

## 3. 功能需求

### 3.1 用户管理子系统

#### 3.1.1 用户注册
- **功能描述**: 用户可以通过邮箱或用户名注册账号
- **输入**: 用户名、密码、邮箱
- **输出**: 注册成功/失败提示
- **优先级**: MVP 必须实现

#### 3.1.2 用户登录
- **功能描述**: 用户使用账号密码登录系统
- **输入**: 用户名/邮箱、密码
- **输出**: JWT Token、用户信息
- **优先级**: MVP 必须实现

#### 3.1.3 用户退出
- **功能描述**: 用户退出登录状态
- **输出**: 登出成功提示
- **优先级**: MVP 必须实现

#### 3.1.4 JWT 身份认证
- **功能描述**: 基于 JWT 的身份验证机制
- **输出**: Access Token + Refresh Token
- **优先级**: MVP 必须实现

#### 3.1.5 用户信息管理
- **功能描述**: 用户可以查看和修改个人信息
- **输入**: 用户名、邮箱、头像
- **输出**: 更新后的用户信息
- **优先级**: MVP 必须实现

#### 3.1.6 密码修改
- **功能描述**: 用户可以修改登录密码
- **输入**: 原密码、新密码
- **输出**: 修改成功/失败提示
- **优先级**: MVP 必须实现

#### 3.1.7 用户绘本项目管理
- **功能描述**: 用户可以查看、删除自己创建的绘本
- **输出**: 绘本列表、操作结果
- **优先级**: MVP 必须实现

### 3.2 智能图像生成子系统

#### 3.2.1 文本解析
- **功能描述**: 解析用户输入的自然语言描述
- **输入**: 用户故事文本
- **输出**: 结构化绘本描述
- **优先级**: MVP 必须实现

#### 3.2.2 Prompt 解析与优化
- **功能描述**: 将结构化描述转换为图像生成提示词
- **输入**: 结构化绘本描述
- **输出**: 优化后的 Prompt
- **优先级**: MVP 必须实现

#### 3.2.3 儿童绘本场景理解
- **功能描述**: 针对儿童绘本的特点进行场景理解
- **输出**: 适合儿童的风格和内容
- **优先级**: 第二阶段实现

#### 3.2.4 图像生成
- **功能描述**: 调用 AI API 生成图像
- **输入**: 优化后的 Prompt
- **输出**: 生成的图像
- **优先级**: MVP 必须实现

#### 3.2.5 生成结果预览
- **功能描述**: 展示生成的图像供用户预览
- **输出**: 图像预览界面
- **优先级**: MVP 必须实现

#### 3.2.6 重新生成
- **功能描述**: 用户可以重新生成图像
- **输出**: 新的生成图像
- **优先级**: MVP 必须实现

#### 3.2.7 生成任务状态管理
- **功能描述**: 跟踪和管理图像生成任务的状态
- **输出**: 任务状态信息
- **优先级**: MVP 必须实现

#### 3.2.8 生成历史
- **功能描述**: 记录和展示用户的生成历史
- **输出**: 历史记录列表
- **优先级**: 第二阶段实现

#### 3.2.9 角色管理/角色一致性
- **功能描述**: 管理角色信息，确保多页绘本中人物一致性
- **输出**: 角色列表、一致性图像
- **优先级**: 第二阶段实现

### 3.3 在线编辑子系统

#### 3.3.1 图片上传
- **功能描述**: 用户可以上传本地图片
- **输入**: 图片文件
- **输出**: 上传成功的图片
- **优先级**: MVP 必须实现

#### 3.3.2 图片缩放
- **功能描述**: 调整图片大小
- **输入**: 缩放比例
- **输出**: 调整后的图片
- **优先级**: MVP 必须实现

#### 3.3.3 图片移动
- **功能描述**: 移动图片位置
- **输入**: 目标位置坐标
- **输出**: 移动后的图片
- **优先级**: MVP 必须实现

#### 3.3.4 图片旋转
- **功能描述**: 旋转图片角度
- **输入**: 旋转角度
- **输出**: 旋转后的图片
- **优先级**: MVP 必须实现

#### 3.3.5 图片裁剪
- **功能描述**: 裁剪图片区域
- **输入**: 裁剪区域
- **输出**: 裁剪后的图片
- **优先级**: 第二阶段实现

#### 3.3.6 添加文字
- **功能描述**: 在页面上添加文字元素
- **输入**: 文字内容、位置、样式
- **输出**: 添加文字后的页面
- **优先级**: MVP 必须实现

#### 3.3.7 修改文字
- **功能描述**: 修改已存在的文字内容
- **输入**: 新的文字内容
- **输出**: 修改后的文字
- **优先级**: MVP 必须实现

#### 3.3.8 调整字体、字号
- **功能描述**: 修改文字的字体和大小
- **输入**: 字体、字号参数
- **输出**: 调整后的文字
- **优先级**: MVP 必须实现

#### 3.3.9 调整文字位置
- **功能描述**: 移动文字位置
- **输入**: 目标位置坐标
- **输出**: 移动后的文字
- **优先级**: MVP 必须实现

#### 3.3.10 图文排版
- **功能描述**: 协调图片和文字的布局
- **输出**: 排版后的页面
- **优先级**: MVP 必须实现

#### 3.3.11 撤销/重做
- **功能描述**: 支持操作的撤销和重做
- **输出**: 操作历史
- **优先级**: MVP 必须实现

#### 3.3.12 页面管理
- **功能描述**: 管理绘本的多个页面
- **输出**: 页面列表、操作结果
- **优先级**: MVP 必须实现

#### 3.3.13 保存绘本
- **功能描述**: 保存绘本项目
- **输出**: 保存成功提示
- **优先级**: MVP 必须实现

#### 3.3.14 导出绘本
- **功能描述**: 导出绘本为文件
- **输入**: 导出格式（PNG/JPEG/PDF）
- **输出**: 导出的文件
- **优先级**: MVP 必须实现

## 4. 非功能需求

### 4.1 性能要求
- 页面加载时间：< 3 秒
- API 响应时间：< 500ms（非 AI 任务）
- AI 生成任务：异步处理，不阻塞用户操作
- 支持并发用户数：100+

### 4.2 可用性要求
- 界面简洁直观
- 操作流程清晰
- 提供必要的操作提示和反馈

### 4.3 可靠性要求
- 系统稳定运行
- 数据定期备份
- 错误处理完善

### 4.4 安全性要求
- 用户密码加密存储
- JWT 认证机制
- API 权限控制
- 文件上传安全检查

### 4.5 可维护性要求
- 代码结构清晰
- 模块化设计
- 完善的日志记录

## 6. 用例分析

### 6.1 用例图

```
用户
  |
  ├── 注册账号
  ├── 登录系统
  ├── 创建绘本项目
  ├── 输入故事文本
  ├── 生成 AI 图像
  ├── 编辑页面元素
  ├── 保存绘本
  ├── 导出绘本
  └── 管理个人绘本
```

### 6.2 核心用例描述

#### 用例 1: 用户注册
- **参与者**: 访客
- **前置条件**: 无
- **基本流程**:
  1. 访客点击注册按钮
  2. 系统显示注册表单
  3. 访客填写用户名、邮箱、密码
  4. 系统验证输入
  5. 系统创建用户账号
  6. 系统返回注册成功
- **后置条件**: 用户账号创建成功

#### 用例 2: 创建绘本
- **参与者**: 已登录用户
- **前置条件**: 用户已登录
- **基本流程**:
  1. 用户点击创建绘本按钮
  2. 系统显示创建表单
  3. 用户填写绘本标题、描述
  4. 系统创建绘本项目
  5. 系统返回创建成功
- **后置条件**: 绘本项目创建成功

## 7. 核心业务流程

### 7.1 用户注册/登录流程

```
访问首页 → 注册/登录 → 进入系统 → 使用功能
```

### 7.2 绘本创建流程

```
登录 → 创建绘本 → 输入故事 → AI生成 → 编辑 → 保存 → 导出
```

### 7.3 AI 图像生成流程

```
用户输入 → 文本解析 → 结构化描述 → Prompt优化 → API调用 → 图像生成 → 预览
```

### 7.4 绘本编辑流程

```
选择页面 → 添加元素 → 编辑属性 → 预览效果 → 保存
```

### 7.5 导出流程

```
选择导出格式 → 生成文件 → 下载文件
```

## 8. 异常情况

### 8.1 网络异常
- AI API 调用超时
- 网络连接中断
- 服务器无响应

### 8.2 数据异常
- 用户输入非法字符
- 文件格式不支持
- 文件大小超限

### 8.3 业务异常
- 用户名已存在
- 密码错误
- 权限不足
- 资源不存在

---

## 9. 权限需求

### 9.1 访问控制
- 未登录用户：只能访问注册/登录页面
- 已登录用户：可以访问所有个人功能
- 用户只能操作自己的绘本

### 9.2 API 权限
- 公开 API：注册、登录
- 认证 API：需要 JWT Token
- 资源 API：需要资源所有权验证

---

## 10. 数据安全要求

### 10.1 密码安全
- 使用 bcrypt 加盐哈希存储
- 密码强度要求：最少 8 位，包含字母和数字

### 10.2 数据传输
- 使用 HTTPS 加密传输
- JWT Token 安全存储

### 10.3 数据存储
- 敏感信息加密存储
- 定期数据备份
