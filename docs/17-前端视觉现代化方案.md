## 1. 背景与目标

### 1.1 现状问题（截至 2026-10-07 的代码事实）

| 问题 | 证据 | 影响 |
|------|------|------|
| **AntD 纯默认主题**：全项目无 `ConfigProvider` | `main.tsx`（仅 10 行）直接渲染 `<App/>`；`App.tsx:30-72` 内也无 | 品牌色 `#1677ff`、默认 6px 圆角与产品气质无关；圆角只能逐处 `!rounded-2xl` 硬打（**9 处**：`GenerationForm.tsx:90`、`BookCard.tsx:22`、`GenerationHistory.tsx:37`、`ResultPreview.tsx:95`、`GenerationProgress.tsx:51`、`GuestGenerator.tsx:60`、`BookDetail.tsx:135,180`、`Generate.tsx:156`） |
| **无设计系统底座** | `tailwind.config.js:7-9` `theme.extend` 为空；`styles/globals.css` 全文 12 行（3 行 @tailwind + body margin + 系统字体栈）；`index.html` 无任何字体/资源 link | 自定义样式没有落点 |
| **无共享布局** | `components/layout/` 仅 `.gitkeep`；全站 **10 处** `min-h-screen` 页面容器各自为政 | 导航靠页内散落按钮（`Generate.tsx:93-110`、`BookList.tsx:84`） |
| **背景三套并存互不连贯** | 6 处硬编码 hex 渐变 `from-[#F5F3FF] via-white to-[#EEF2FF]`（`Home.tsx:16`、`Generate.tsx:91`、`BookList.tsx:72`、`BookDetail.tsx:100/108/124`）vs 3 处 `from-blue-50 to-purple-50`（`Home.tsx:43`、`Login.tsx:22`、`Register.tsx:33`）vs `bg-gray-50`（`Profile.tsx:13`）；另有裸 `slate-*` 5 处 | 同一 App 视觉割裂 |
| **核心概念零视觉表现** | `StyleSelector.tsx:20-29` 名不副实，只是一个裸 `<Select>`，5 种艺术风格无缩略/色卡 | 儿童绘本产品的卖点抽象不可见 |
| **无动效/骨架屏** | 全站唯一动效为 `BookCard.tsx:22` 一组 hover 过渡；结果图为裸 `<img>`（`GuestGenerator.tsx:86-92`、`ResultPreview.tsx:122-125`）；进度条为硬编码假百分比（`GenerationProgress.tsx:27-40`：pending 15% / processing 60%） | 生成等待体验差 |
| **AntD 5 API 债务** | `bodyStyle`（`BookCard.tsx:21`）；静态 `message.*` **16 处 / 8 文件**（不继承主题，含非组件文件 `api/client.ts:192`）；`destroyOnClose`（`BookFormModal.tsx:63`、`SaveToBookModal.tsx:117`） | 弃用警告 + 未来升级隐患 |
| 其他 | 无暗色、无 zh_CN locale（Pagination 等仍显英文）、`index.html:5` 引 `/favicon.ico` 但 `public/` 无该文件（404） | 细节观感 |

> **版本事实**：`package.json:15` 声明 `antd ^5.12.0`，lockfile 实装 **5.29.3**（React 18.3.1、tailwind 3.4.19）。`Card.styles.body`、`Modal.destroyOnHidden`、`ConfigProvider.cssVar`、`Card.variant` 均可用；**不要因为"按 5.12 写"而退回旧 API**。

### 1.2 目标风格

**简约油画风**，参考 Google 搜索页的构图纪律：

- **大面积干净留白**：纯白/暖灰白画布底，元素克制；
- **居中构图**：游客首页 = 艺术字 logo + 一句话副标 + 居中生成器卡（类比 Google 的 logo + 搜索框）；
- **暖色点缀**：品牌色只出现在 logo、主 CTA、选中态，绝不铺满；
- **艺术字彩绘 logo**：多彩字母（Google logo 式逐字母换色），契合绘本调性；
- **轻快动效**：150–450ms 的入场/淡入/hover，点到为止。

### 1.3 范围与三条边界

范围 = 主题底座 + 共享布局 + 关键组件升级（非全页面重做）。

| 边界 | 内容 |
|------|------|
| 不做暗色模式 | 只做浅色一套主题 |
| 不引新依赖 | 动效走纯 CSS/Tailwind keyframes；**否决 framer-motion**（需求全部 CSS 可表达，+30–50KB gzip 不值）；不换 lucide（23 个 `*Outlined` 图标保留，仅少量引入 `Filled` 变体） |
| 不动业务逻辑 | `api/*`、`stores/*`、`hooks/*` 语义与签名不变；`App.tsx` 路由、`ProtectedRoute`、`ensureGuestToken`（`App.tsx:24-28`）原样；`api/client.ts` 仅允许替换 message 来源，401 单飞刷新/游客重建冷却（`client.ts:109-137`）/静默轮询逻辑一行不动 |

## 2. 设计令牌体系

### 2.1 色板（暖白画布 + 陶土主色 + 油画点缀）

| 令牌 | 值 | 用途 |
|------|-----|------|
| `sc-canvas` | `#FDFBF7` | 页面底（**全站唯一底色**，取代全部渐变/gray/slate） |
| `sc-canvas-2` | `#F6F0E7` | 次级底：空态、hover、骨架、Tag 底 |
| `sc-paper` | `#FFFFFF` | 卡片与浮层 |
| `sc-ink` | `#2B2621` | 主文本（暖黑） |
| `sc-ink-2` | `#6E655C` | 次文本 |
| `sc-ink-3` | `#9A9086` | 辅助/占位 |
| `sc-hairline` | `#E9E1D6` | 1px 边框（暖灰，替代 antd 冷色 `colorBorder`） |
| `sc-clay` | `#C0522F` | **colorPrimary**（陶土/burnt sienna）。白字对比度 **4.67:1**，按 WCAG 相对亮度公式核算 ≥ AA(4.5) |
| `sc-clay-hov` / `sc-clay-act` | `#D2663F` / `#A5442A` | 主色 hover / 按下 |
| `sc-amber` | `#E2A13C` | 进度与「生成中」强调 |
| logo 五色环 | poppy `#D2433B`、amber `#E2A13C`、leaf `#6FA96B`、sky `#4E86BE`、plum `#8E5B9F` | **仅用于 logo 字母 / 选中态 / 状态点**，不用于小字、不铺满 |

> 选陶土而非 antd 默认蓝：更暖、贴油画/绘本调性，与 mock 出图的暖调不冲突。sky/plum 饱和度已下调，避免在近白底上「糊色」。

### 2.2 字体（决策：零外链）

**否决 Google Fonts**：产品有「离线可跑」演示诉求（README 核心功能段），外链引入 FOUT、首屏阻塞、断网字体抖动。

```
UI 正文（font-sans）：
  'PingFang SC','Hiragino Sans GB','Microsoft YaHei','Source Han Sans SC',
  'Noto Sans CJK SC',system-ui,-apple-system,'Segoe UI',Roboto,'Helvetica Neue',sans-serif
Logo 艺术字（font-display）：
  Georgia,'Songti SC','STSong','SimSun',serif + font-weight:700 + letter-spacing:-0.015em
```

中文「艺术感」来自**配色 + 字重 + 字距 + 逐字母入场动效**，而非特定字体（跨平台中文字形不可控，不做中文艺术字）。
可选后续项（本次不做）：`public/fonts/*.woff2` 子集自托管（30–80KB）+ `font-display: swap`。

**Logo 实现**：`Wordmark.tsx` 把 `StoryCanvas` 拆字母数组，逐字母 `<span style={{color: LOGO_COLORS[i % 5]}}>`（首尾落暖色），容器 `aria-label` + 字母 `aria-hidden`；入场 `animate-paint-in` 每字母 40ms stagger。
否决 `background-clip:text` 渐变字：① Google 是逐字母不同色而非渐变；② **html2canvas 不支持该属性**，留 PDF 坑。

### 2.5 动效规范

纯 CSS/Tailwind keyframes（不引动画库），时长一律 **150–450ms**，缓动 `cubic-bezier(.22,.61,.36,1)`：

| 动效 | 用法 | 落点 |
|------|------|------|
| `animate-enter`（fadeUp .5s） | 页面主体入场：Home/Generate/BookList/BookDetail | tailwind config |
| `animate-paint-in` + `animationDelay: i*40ms` | logo 逐字母 | Wordmark |
| `animate-fade`（fadeIn .35s） | 图片加载完成淡入 | **仅限 `.sc-artimg` 显式类**（红线，见 §8.1） |
| `shimmer` | 骨架屏 `.sc-skeleton` | globals.css |
| hover：`hover:-translate-y-1 hover:shadow-lift`、`active:scale-[0.98]` | 卡片沿用 `BookCard.tsx:22` 手法、阴影从冷 `shadow-xl` 换暖 `shadow-lift`，加 `transition-[transform,box-shadow] duration-200` | 各组件 |

`globals.css` 附：`@media (prefers-reduced-motion: reduce)` 下上述动画一律 `animation:none`。

## 3. 共享布局

### 3.1 决策：极简顶栏，无 Sidebar

`docs/07 §2` 与 `components/layout/.gitkeep` 预留了 Header/Sidebar 命名。本次采纳 Header（命名 `AppHeader`），**否决 Sidebar**：全站仅 6 条路由，Google 首页靠「零导航 + 右上角登录」建立聚焦感，侧栏破坏留白。（`docs/07` 相应措辞待实施阶段随文档一并修订。）

新建 4 个文件：

```
components/layout/AppLayout.tsx   props: variant:'hero'|'app'|'auth'; children
components/layout/AppHeader.tsx   导航 + 登录/游客状态区分
components/layout/PageHeader.tsx  props: title, description?, extra?, onBack?, backLabel?
components/layout/Wordmark.tsx    props: size:'hero'|'nav'; tagline?
```

三种形态（`AppLayout` 是全站唯一背景源）：

| variant | 结构 | 用于 |
|---------|------|------|
| `hero` | `min-h-screen bg-canvas` + **绝对定位右上角**：游客显示「登录 ghost / 注册 primary pill」，已登录显示头像 Dropdown。无顶栏，最接近 Google 首页 | Home 游客态 |
| `app` | `min-h-screen bg-canvas flex flex-col` + sticky 顶栏 `h-16 border-b border-hairline bg-paper/80 backdrop-blur`：左 Wordmark(nav)→`/`，导航「首页 / · AI 生成 /generate · 我的绘本 /books（仅登录）」，右：登录态 `Avatar + Dropdown{个人中心/退出}`，游客态「登录/注册」。移动端 `<md` 隐藏文字导航、收进 Dropdown（不加新依赖，不用 Menu） | Generate / BookList / BookDetail / Profile / Home 登录态 |
| `auth` | `bg-canvas` 居中列：Wordmark 在上、卡片在下，无导航，含「返回体验首页」链接 | Login / Register |

### 3.2 接入方式：页面自持 layout，不改路由树

| 候选 | 说明 | 决策 |
|------|------|------|
| **A. 每页替换最外层容器** | 各页面把 `div.min-h-screen.bg-gradient…` 换成 `<AppLayout variant=…>`；`App.tsx` 完全不动 | ✅ **采纳**。路由与 `ProtectedRoute`/`ensureGuestToken` 零改动，Home 可单独用 hero |
| B. layout route + `<Outlet/>` | 一处化更彻底，但需重排 `Routes` 嵌套，与「路由不变」约束摩擦 | 留作后续演进 |

页面替换清单（精确到行）：

| 文件 | 现容器 | 改为 |
|------|--------|------|
| `Home.tsx:16` / `:43` | 两套渐变 | `variant="hero"` / `variant="app"` |
| `Generate.tsx:91` | hex 渐变 | `AppLayout(app)` + `PageHeader`；**删 L93-110「返回/首页」按钮组**（归顶栏），保留「重新开始」 |
| `BookList.tsx:72` | hex 渐变 | `AppLayout(app)` + `PageHeader(extra=新建绘本按钮)`；删 L84「返回首页」 |
| `BookDetail.tsx:100/108/124` | 3 处 hex 渐变 | `AppLayout(app)` 单容器；loading `Spin`→`Skeleton`；`:126-133` 返回按钮改 `PageHeader onBack` |
| `Profile.tsx:13` | `bg-gray-50` + 裸 Card | `AppLayout(app)` + `PageHeader`；Card 走 token；退出登录移入顶栏（页内可留一个 danger text 入口，避免功能缺失感） |
| `Login.tsx:22` / `Register.tsx:33` | `blue-50→purple-50` | `AppLayout(variant="auth")` + 上方 Wordmark；Card `shadow-lg`→`shadow-card`；Input/按钮 `size=large` |

结果：页面层 `min-h-screen`/`bg-gradient`/`bg-gray-50` 清零（10 → 0），背景与导航单点可控。

## 4. 关键组件升级

### 4.1 Home 首页（Google 式居中 hero）

**游客形态**（现 `Home.tsx:14-39`）：

```

  Wordmark size="hero"（48–64px 多色字母 + paint-in stagger）
  副标一句：「把一段故事，画成一幅绘本插画」（替换现 L22-24 学术长句）
  GuestGenerator 卡（即"搜索框"）：rounded-card shadow-card ring-hairline
  小字：「免费 1 张 · 无需注册 · 登录后可保存到绘本并导出 PDF」（额度取 GUEST_GENERATION_LIMIT）
```

- 删除 L25-32「登录/注册」双按钮（移右上角，对齐 Google 信息层级）。
- `GuestGenerator` 语义/props 不变（`GuestGenerator.tsx:60-118`）。
- **可选 delight**：hero 底 3 个「示例故事」chip，点击经 `GenerationForm.initialText`（已有 prop，L21）回填；不改 `SAMPLE_TEXT` 常量语义。

**已登录形态**（现 L42-73「按钮清单卡」）→ `PageHeader` 问候（保留 L58-60 引导文案）+ 居中「开始创作」大 CTA + 3 个入口 tile（我的绘本/个人中心/导出 PDF 说明）。删 L68 退出按钮（顶栏已有）。**刻意不加统计数字**（需要新 store 读取，越出视觉边界）。

**容器嵌套修正**：现 `GuestGenerator.tsx:60` 外层 Card 内又套 `GenerationForm.tsx:88` 的 Card（Card-in-Card）。改法：`GenerationForm` 不再自带 Card（返回 Form 本体，保留 `submitText` prop），容器交还宿主——GuestGenerator 提供 pill 卡外壳、`Generate.tsx:124` 外包 token 化 Card。涉及 2 个宿主，无逻辑风险。

### 4.2 StyleSelector：裸 Select → 调色板色卡

**对外契约不变**：`{ value?, onChange?, disabled?, className? }`（`StyleSelector.tsx:6-11`）——`GenerationForm.tsx` 的 `<Form.Item name="style">` 包裹与 `Generate.tsx:80-84` 历史回填均不受影响。

渲染 5 卡网格（`grid grid-cols-2 sm:grid-cols-3 lg:grid-cols-5 gap-2`）：每卡 = 顶部 36–44px「调色板笔触条」+ 名称 + 一行描述。

- **色卡数据源复用后端真 palette**（跨栈一致性，答辩叙事）：`ai-service/app/prompts/styles/*.py` 每套风格已含 4 色，如 oil_painting（`oil_painting.py:17`）`["#8D6E63","#C62828","#F9A825","#1565C0"]`、watercolor `["#FFE3E3","#E2F2FD","#E8F5E9","#FFF8E1"]`、cartoon、anime、pencil_sketch 各 4 色。笔触条用**硬分段渐变**（比重渐变更有调色感）：`linear-gradient(135deg, p0 0 30%, p1 30% 55%, p2 55% 80%, p3 80% 100%)`。
- 选中态：`ring-2 ring-clay` + 右上 `CheckCircleFilled`（不只靠颜色，满足 a11y）+ `shadow-card`；未选 `bg-canvas2`；卡为 `<button type="button" aria-pressed>`，hover 轻微上移，`disabled` 全禁用。
- **决策：纯 CSS 色卡，不用静态图**——不新增二进制资源、零网络请求、离线安全；真实缩略图需人工备 5 张样图或依赖 mock 出图（不稳定），性价比差。

## 8. 风险与红线

### 8.1 html2canvas / PDF 导出红线（第一优先）

`utils/pdf.ts:46-63` 的做法：构造离屏 `div`（inline cssText，`background:#ffffff`）+ **裸 `document.createElement('img')` 直接 `document.body.appendChild`**，再交 html2canvas 截图。因此：

- **禁止任何元素级全局样式动画/滤镜**（`img{animation}`、`div{transition}`、`body *{…}`）——PDF 渲染时图片可能在 `opacity<1` 瞬间被抓取 → **空白页**。淡入只能挂显式类 `.sc-artimg`（仅 `ArtImage` 内部使用），pdf.ts 的裸 `<img>` 不会命中。
- 禁止给 PDF 导出路径涉及的样式引入 `filter` / `backdrop-filter` / `background-clip:text` / 复杂 `conic/radial` 渐变（html2canvas 1.4.1 不支持或降级）。顶栏的 `backdrop-blur` 与导出离屏容器无关，可放心使用。
- **不改 `pdf.ts:47` 的 cssText**（其字体栈 `-apple-system,"PingFang SC","Microsoft YaHei"` 与新 UI 字体栈不冲突，PDF 观感独立）。
- 主题色走 `:root` 变量，html2canvas 读 computed style 不受 `var()` 影响；但 palette 变量若缺失会产生 `rgb(NaN)` 类问题——因此建议加一个约 20 行的 vitest：读 `globals.css` 解析 `--sc-*` 与 `palette.ts` 的 hex→rgb 比对，**防双源漂移**。

### 8.2 其余约束

| 风险 | 对策 |
|------|------|
| 越界改动业务逻辑 | 不动 `api/*`（client.ts 仅换 message 来源）、`stores/*`、`hooks/*`、`App.tsx` 路由与 guest 逻辑 |
| `constants.ts` 测试兼容 | **只增不改**：`ART_STYLE_OPTIONS`（as const 5 项）、`TASK_STATUS_TEXT/COLOR`、`IMAGE_SIZE_OPTIONS`、`MAX_PAGES_PER_BOOK`、`STORY_TEXT_MAX_LENGTH`、`GUEST_GENERATION_LIMIT`、`BOOK_STATUS_*` 原样；新视觉元数据放新导出 `ART_STYLE_META` |
| React StrictMode 双挂载（`main.tsx:7`） | 新增计时/缓动 effect 必须返回 cleanup 并防重复计时 |
| antd token 细节 | `genRadius` 封顶规则 → 必须**显式**覆盖 `borderRadiusLG/SM`；Button 无 `borderRadius` component token；Alert 可调 token 极少（靠全局色）；`cssVar:true` 需 React 18（满足） |
| Tailwind × var × alpha | 必须 `rgb(var() / <alpha-value>)` 三元组（§2.3）；`@layer base` 保持轻，避免与 antd cssinjs 注入顺序产生新覆盖需求 |
| 中文 logo 跨平台字形 | 艺术感来自配色/字重/字距/动效，不绑定特定字体；零外部字体请求（对齐离线演示） |
| 范围蔓延 | 不做暗色、不做全页面重做、不引动画/图标库；Home 统计数字等需求一律列入 TODO 另评 |
