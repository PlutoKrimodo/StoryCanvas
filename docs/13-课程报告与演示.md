## 3. 演示流程设计

### 3.1 演示目标

- 展示系统核心功能
- 体现 AI 技术应用
- 展示系统架构设计
- 控制在 5-10 分钟

### 3.2 演示流程（5 分钟版）

```
1. 开场介绍（20 秒）
   - 项目名称
   - 核心功能
   - 技术亮点

2. 游客直接体验（60 秒）
   - 打开首页（无需登录）即生成器
   - 输入故事，生成 1 张插画
   - 展示结果与「登录后保存」引导

3. 注册 / 登录并认领（40 秒）
   - 注册（邮箱 + 用户名 + 密码）
   - 登录后游客结果自动认领到账号

4. 对话式多图创作（2 分钟）
   - 进入生成页输入故事
   - 展示 AI 分镜与角色/风格设定
   - 确认后一次生成 4 张
   - 预览、单格重画

5. 保存到绘本 / 导出多页 PDF（40 秒）
   - 整组保存到绘本
   - 在绘本详情页导出含中文页标题的多页 PDF

6. 总结（20 秒）
   - 功能总结
   - 技术亮点
   - 未来展望
```

### 3.3 演示流程（10 分钟版）

```
1. 开场介绍（1 分钟）
   - 项目背景
   - 系统架构
   - 技术栈介绍

2. 游客体验与认领（1.5 分钟）
   - 首页游客生成 1 张
   - 触发额度/登录引导
   - 注册登录后认领归属

3. 对话式多图（3 分钟）
   - 故事输入
   - AI 分镜与 Prompt 优化展示
   - 确认分镜后批量生成
   - 生成结果预览与单格重画

4. 保存与导出（1 分钟）
   - 整组保存到绘本
   - 生成历史与参数复用
   - 导出多页 PDF

5. BYOK 与成本闸门（1.5 分钟）
   - 个人中心配置自带 Key（脱敏回显）
   - 双项配置时任务不占每日额度
   - 展示游客池 / 登录池额度文案

6. 安全演示（1 分钟）
   - 密码 bcrypt 哈希入库
   - 游客写接口 403 / 越权 403 / 限流 429
   - 接口限流与每日额度两道闸门

7. 总结（30 秒）
   - 功能总结
   - 技术亮点
```

### 3.4 演示要点

#### 最值得展示的功能

1. **AI 图像生成 + 对话式多图**
   - 展示 AI 理解文本的能力
   - 展示分镜与 Prompt 优化效果
   - 展示一次生成 1/2/4/6 张与单格重画

2. **生成任务异步机制**
   - 展示任务状态流转（pending → processing → completed）
   - 展示失败重试与超时控制

3. **Guest-first 游客体验**
   - 未登录直接生成
   - 登录后自动认领游客结果
   - 游客写接口 403、额度 429 的产品闭环

4. **账号安全与加密存储**
   - 展示密码 bcrypt 哈希入库（非明文）
   - 展示越权访问 403、限流 429
   - 展示 BYOK 凭据 AES-256-GCM 密文与脱敏回显

5. **绘本 PDF 导出（轻量多页）**
   - 展示「保存到绘本 → 导出含中文页标题的多页 PDF」
   - 说明 PDF 由前端生成、不依赖服务端排版

6. **成本闸门**
   - 游客池 / 登录用户池两套每日额度
   - 双项 BYOK 不占池，系统 Key 成本可控

> 原「在线编辑器」「多页手动排版」演示要点已随在线编辑子系统一并移除；PDF 导出以「轻量多页（前端生成）」形式加回。

#### 演示技巧

1. **提前准备**: 使用预设的演示数据，并提前用真实厂商预生成 2-3 张备份图
2. **网络稳定**: 确保国内厂商 API（DeepSeek / 豆包 / 通义万相）可用；如异常将 `IMAGE_PROVIDER` 切为 `mock`
3. **备份方案**: 准备截图或视频作为备份
4. **时间控制**: 严格控制每个环节的时间

### 3.6 演示配置 vs 提交配置（Q2）

额度按 **Asia/Shanghai 自然日**重置，**演示当天一旦打满只能等次日**，因此演示前必须单独准备一份配置：

| 配置项 | 提交配置 | 演示配置（建议） | 说明 |
|--------|---------|----------------|------|
| `GUEST_DAILY_GENERATION_CAP` | 20 | 100 | 现场多人体验游客生成 |
| `USER_DAILY_GENERATION_CAP` | 50 | 200 | 登录用户演示与答辩补充 |
| `RATE_LIMIT_GENERATION_PER_MIN` | 10 | 30 | 避免连续点按触发 429 |
| `TASK_RETRY_COUNT` | 2 | 2 | 不建议调高；成本按任务数 ×2 估算 |
| `BYOK_ENABLED` | true | true | 自带 Key 的用户不占池，可现场演示 |
| `LLM_PROVIDER` / `IMAGE_PROVIDER` | 真实厂商 | 真实优先，`mock` 兜底 | 断网或欠费时切 mock，链路仍可跑 |

操作口径：

- 演示配置写入独立文件（如 `.env.demo`，**不入库**），演示前复制为 `.env` 并重启 backend / ai-service；
- 演示前用 mock 跑通一次「生成 → 保存到绘本 → 导出 PDF」，同时确认两池额度未被预演打满；
- 演示结束恢复提交配置，仓库与报告中只保留提交配置；
- 若当天额度已被预演打满，可临时调高两池或改用 mock（成本为 0）。
