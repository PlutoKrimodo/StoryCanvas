## 3. 演示流程设计

### 3.1 演示目标

- 展示系统核心功能
- 体现 AI 技术应用
- 展示系统架构设计
- 控制在 5-10 分钟

### 3.2 演示流程（5 分钟版）

```
1. 开场介绍（30 秒）
   - 项目名称
   - 核心功能
   - 技术亮点

2. 用户注册（30 秒）
   - 打开注册页面
   - 输入用户名、邮箱、密码
   - 完成注册

3. 用户登录（20 秒）
   - 输入账号密码
   - 登录成功
   - 展示首页

4. 创建绘本（20 秒）
   - 点击创建绘本
   - 输入标题和描述
   - 创建成功

5. AI 图像生成（2 分 30 秒）
   - 输入故事文本
   - 选择艺术风格
   - 展示 AI 解析结果
   - 点击生成并展示进度
   - 展示生成结果

6. 结果预览与重新生成（40 秒）
   - 放大查看生成结果
   - 基于原任务重新生成
   - 对比两次结果

7. 保存到绘本 / 下载图片（20 秒）
   - 保存生成结果到绘本
   - 下载单张图片

8. 总结（30 秒）
   - 功能总结
   - 技术亮点
   - 未来展望
```

### 3.3 演示流程（10 分钟版）

```
1. 开场介绍（1 分钟）
   - 项目背景
   - 系统架构
   - 技术栈介绍

2. 用户系统（1 分钟）
   - 注册演示
   - 登录演示
   - 用户信息管理

3. 绘本管理（1 分钟）
   - 创建绘本
   - 绘本列表
   - 绘本详情

4. AI 图像生成（4 分钟）
   - 文本输入
   - AI 文本解析与 Prompt 优化展示
   - 图像生成过程
   - 生成结果预览
   - 重新生成

5. 生成历史与结果管理（1 分钟）
   - 历史记录列表
   - 结果复用与下载

6. 安全与加密（1 分钟）
   - 密码 bcrypt 哈希入库演示
   - 越权访问被拒 / 限流

7. 总结（30 秒）
   - 功能总结
   - 技术亮点
```

### 3.4 演示要点

#### 最值得展示的功能

1. **AI 图像生成**
   - 展示 AI 理解文本的能力
   - 展示 Prompt 优化效果
   - 展示图像生成与结果预览

2. **生成任务异步机制**
   - 展示任务状态流转（pending → processing → completed）
   - 展示失败重试与超时控制

3. **账号安全与加密存储**
   - 展示密码 bcrypt 哈希入库（非明文）
   - 展示越权访问与限流防护

> 原「在线编辑器」「多页绘本」演示要点已随在线编辑子系统一并移除。

#### 演示技巧

1. **提前准备**: 使用预设的演示数据
2. **网络稳定**: 确保 AI API 可用
3. **备份方案**: 准备截图或视频作为备份
4. **时间控制**: 严格控制每个环节的时间

### 3.5 演示准备清单

```
□ 环境准备
  □ 本地服务启动
  □ 数据库初始化
  □ 测试数据准备
  □ 网络连接检查

□ 演示材料
  □ 演示文稿（可选）
  □ 演示脚本
  □ 备份截图/视频

□ 设备检查
  □ 电脑性能
  □ 屏幕分辨率
  □ 投影设备

□ 应急预案
  □ API 失败处理
  □ 网络断开处理
  □ 备用演示方案
```
